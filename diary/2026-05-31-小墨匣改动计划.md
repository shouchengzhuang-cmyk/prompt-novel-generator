四、今日建议继续做的第三刀
第三刀：编辑室聊天持久化

当前问题：

编辑室聊天记录如果仍然只存在内存或 session 中，服务重启后会丢失。这个问题属于“止血稳定期”的最后一块。

目标：

每个项目新增：

editor-chat.json

建议结构：

{
  "version": 1,
  "messages": [
    {
      "id": "timestamp-or-uuid",
      "role": "user",
      "content": "用户消息",
      "createdAt": "ISO 时间"
    },
    {
      "id": "timestamp-or-uuid",
      "role": "assistant",
      "content": "AI 回复",
      "createdAt": "ISO 时间"
    }
  ]
}

要求：

每个项目单独保存编辑室聊天记录
写入必须走 writeJson / atomicWrite
文件不存在时返回空消息数组
最多保留最近 100 条消息
单条消息限制长度，避免文件无限膨胀
editor-chat.json 损坏时不能直接覆盖，应该备份为 .corrupt 或返回错误
不改章节数据结构
不改 variants 数据结构
不大改前端 UI

新增或调整接口建议：

GET    /api/projects/:name/editor-chat
POST   /api/projects/:name/editor-chat
DELETE /api/projects/:name/editor-chat

验收目标：

打开编辑室能加载历史聊天
发送消息后刷新页面仍然存在
PM2 重启后聊天记录仍然存在
清空接口可用
不影响章节生成、重写、保存
