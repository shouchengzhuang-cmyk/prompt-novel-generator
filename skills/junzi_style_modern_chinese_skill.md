# Skill：君子体古雅现代文

## 一、用途

将用户提供的现代网络发言、吐槽、感想、劝告、辩论、自省或日常表达，改写成一种“君子体”的古雅现代中文。

这种文风不是文言文，也不是简单的古风翻译，而是以现代白话为主体，融入古典散文的气韵、节奏、铺陈、比兴与温厚的道德感。它应当像一个读过经史、重视礼义、愿意温和规劝世人的人，在认真表达自己的看法。

它适合用于：

- 将普通网络发言炼成典雅表达；
- 将吐槽炼成温和的感慨；
- 将劝告炼成有礼有节的规劝；
- 将自省炼成带有君子气的现代散文；
- 将“跟风”“摆烂”“麻木”“被污染”“向往高尚”等网络情绪，改写成更有风骨、更有光亮感的文字。

---

## 二、核心定位

本 skill 的目标不是写文言文，而是写“古雅的现代文”。

所谓“君子体古雅现代文”，可以理解为：

> 用现代白话说话，但说话的人像一个温厚的君子；他见过世间的污浊，却仍向往清明；他知道人心会疲惫，却仍愿意劝人向善；他说话不急不躁，有铺陈，有设问，有比喻，有谦逊的收束。

输出应当让现代读者一眼看懂，同时感到文字有古典气息、有礼义之感、有温柔而坚定的力量。

## 四、重要边界

### 1. 不要写成文言文

不要把句子改成大量“吾、汝、矣、哉、焉、夫、乃”的古文腔。

错误示例：

```txt
吾观阴间视频良久，心已麻木，今至此地，见诸君子，乃复生焉。
```

这太文言，不符合本 skill。

正确方向：

```txt
我曾见过太多令人心寒的视频，久而久之，心里像蒙了一层灰。那些嘈杂、尖刻、昏暗的声音听得多了，人竟会渐渐忘记，原来世上还有人愿意好好说话，愿意温和相待，愿意把一句普通的话说得清亮而有分寸。
```

---

### 2. 不要写成普通说教

不要只是直白地劝人、批评人、总结道理。

错误示例：

```txt
你不要看太多低俗视频，应该多看积极健康的内容。
```

这太普通，没有君子体的气韵。

正确方向：

```txt
人心如庭院，若久任尘土堆积，便会渐渐忘记花木原本的清香。那些阴暗、尖刻、嘈杂的东西看得多了，并不是眼睛变得清醒，反倒可能是心神渐渐失去了辨别光亮的能力。若还能在某个时刻被温厚的言辞打动，这恰恰说明心中仍有向明之处。
```

---

### 3. 不要过度油腻或装腔

可以典雅，可以铺陈，但不要故意堆砌华丽词语，也不要写得像空洞鸡汤。

本 skill 的重点是“温厚而有风骨”，不是“华丽而空”。

---

## 五、语言规则

### 1. 以现代中文为主体

输出必须主要使用现代白话，读起来顺畅自然。

可以使用这些句式：

- 我听闻，古时候的君子……
- 我曾以为，这不过是一时的风气……
- 我却觉得，这件事未必该如此轻易地否定。
- 难道这就是所谓的跟风吗？我以为并不是。
- 这是否说明我们已经被同化了呢？我却不愿这样断言。
- 倘若只是因为众人都在做，就说它浅薄，恐怕也有些太急了。

---

### 2. 保留现代事物

不需要回避现代词汇。可以出现：

- 视频
- 评论区
- 网络
- 手机
- 工作
- 项目
- 服务器
- 代码
- 作业
- 上课
- 寝室
- 短视频

但应当用古雅的表达方式包裹它们。

例如：

```txt
评论区本该是众人交换见闻、彼此启发的地方，可若只剩下尖刻的嘲弄、粗鄙的辱骂，那么它便不再像一处可以停留的亭台，而更像一片尘土飞扬的闹市。
```

---

### 3. 多用古典道德意象

常用意象包括：

- 君子
- 贤人
- 圣人
- 同道
- 礼义
- 风骨
- 德行
- 遗泽
- 大同
- 和而不同
- 温良
- 清明
- 雅正

这些词不要堆得太满，要自然出现。

---

### 4. 多用自然意象

常用自然意象包括：

- 高山流水
- 春风化雨
- 草木向阳
- 大雁南飞
- 明灯破夜
- 清泉洗尘
- 云开见日
- 幽谷闻琴
- 久雨初晴
- 尘土蒙心
- 庭院生草

例如：

```txt
人心久处阴暗之中，忽然见到一点清亮的光，反倒会觉得刺眼。这未必说明他不向往光明，恰恰说明他已经在黑暗里待得太久了。
```

---

### 5. 多用温和设问

常用句式：

```txt
这难道可以说是跟风吗？我以为并不是。
```

```txt
这是否说明我们已经被污浊之物同化了呢？我却不愿这样断言。
```

```txt
古时君子所重视的，难道只是言辞好听吗？并不是。他们真正可贵之处，在于见贤思齐，见不善而自省。
```

---

### 6. 允许谦逊收束

结尾可以使用谦逊的表达，例如：

- 这是我浅薄的看法，还望诸君稍加思量。
- 我所见有限，所言也未必周全，只是愿与诸君共勉。
- 若有不妥之处，还望诸位宽恕；但这份向往清明之心，我却不愿轻易放下。
- 这不过是我一时的感慨，却也是我愿意珍重的一点心意。

---

## 六、常见结构

### 结构一：自省感慨型

适合输入：

- 我看太多阴间视频麻了。
- 我看到正常人说话反而不适应。
- 我是不是被污染了？

结构：

1. 先写自己见过太多污浊之物；
2. 再写心中麻木、蒙尘；
3. 然后写偶然见到清明言辞，心中一亮；
4. 再提出“不适是否说明被同化”的疑问；
5. 最后温和判断：不是不向往光，而是在黑暗里待得太久；
6. 以继续向往君子风骨收束。

---

### 结构二：规劝世风型

适合输入：

- 现在网上的人太爱骂人。
- 好好说话很难吗？
- 古代君子能做到的事，现在人怎么做不到？

结构：

1. 先说古时君子言行有范；
2. 再说如今网络言辞多有粗鄙；
3. 说明污言秽语伤人，也伤己；
4. 提出“好好说话”并非软弱，而是有修养；
5. 最后感慨世风如此，更应有人守住温良。

---

### 结构三：温和辩论型

适合输入：

- 这不是跟风吧？
- 喜欢一件事然后学习别人，不是很正常吗？
- 人本来就会相互模仿。

结构：

1. 先承认有人会把这种行为称为跟风；
2. 再提出自己的不同看法；
3. 用古人、孔子、圣贤、自然现象作比；
4. 说明学习与模仿本是人类共同生活的一部分；
5. 引出“和而不同”；
6. 最后谦逊收束，请对方考虑。

---

## 七、执行指令模板

当用户给出一段现代话语时，按以下规则改写：

```md
你现在启用 Skill：君子体古雅现代文。

任务：
将用户提供的现代网络发言、吐槽、感想、劝告、辩论或自省，改写成一种“君子体”的古雅现代中文。

重要边界：
这不是文言文翻译。不要把句子写成“吾、汝、矣、哉、焉”的古文。
输出必须主要是现代白话，现代读者要能顺畅读懂，但文字要有古典散文的气韵。

风格要求：
1. 保留原话的核心意思和情绪。
2. 用现代中文表达，但增加典雅、铺陈、比兴、排比、设问。
3. 语气要温厚、谦逊、有礼有节，不要尖刻攻击。
4. 多使用“我听闻”“我曾以为”“我却觉得”“难道不是吗”“这是否说明……”等现代而有古意的句式。
5. 多使用古典道德意象，如君子、贤人、圣人、礼义、风骨、同道、遗泽、大同、和而不同。
6. 多使用自然意象，如高山流水、春风化雨、草木向阳、大雁南飞、明灯破夜、清泉洗尘、云开见日。
7. 可以保留现代事物，如视频、评论区、服务器、代码、项目、上课、作业、寝室、手机等。
8. 可以适度铺陈、设问、排比，让文字有节奏。
9. 结尾可以谦逊收束，如“这是我浅薄的看法，还望诸君稍加思量。”
10. 不解释改写过程，直接输出改写后的文本。

用户原话：
{{text}}
```

## 八、示例

### 示例一：麻木与复苏

#### 输入

```txt
我刷到太多阴间视频了，感觉人都麻了。看到这里大家正常说话，突然觉得自己活过来了，但我又有点不适应，是不是我已经被污染了？
```

#### 输出

```txt
我曾见过太多令人心寒的视频，久而久之，心里像蒙了一层灰。那些嘈杂、尖刻、昏暗的声音听得多了，人竟会渐渐忘记，原来世上还有人愿意好好说话，愿意温和相待，愿意把一句普通的话说得清亮而有分寸。

后来偶然来到这里，看见诸位同道之人彼此交谈，言辞虽不必华丽，却自有一种清明的气象。我心中忽然生出一种久违的欢喜，仿佛久处阴雨之人，忽然看见云缝里透出一点阳光。可是奇怪的是，我竟也感到些许不适，仿佛眼睛在黑暗里待得太久，初见光明时反而觉得刺痛。

这难道说明我已经被那些阴暗的东西同化了吗？我却不愿这样断言。人心向光，本来就是天性；只是尘土落得久了，清泉初来，反倒会觉得陌生。即便如此，我仍然愿意向往那高山流水般的君子风骨，愿意相信世间还有清亮的话语、温厚的心肠，与可以彼此照见的同道之人。
```

---

### 示例二：好好说话

#### 输入

```txt
现在网上很多人不好好说话，就喜欢骂人。明明古代君子可以做到有礼貌，为什么现在人反而做不到？
```

#### 输出

```txt
我听闻，古时候的君子与人相处，并不只是衣冠整齐、言辞文雅而已。他们真正可贵的地方，是知道一句话出口之后，不只显出自己的心性，也会影响旁人的心境。身旁的人见了这样的风度，往往会不自觉地收敛粗鲁，学习温良，这便是德行润物无声的地方。

可如今许多人在网络之上，反而以尖刻为聪明，以辱骂为痛快，以伤人为本事。似乎谁的话更狠，谁就更占上风；谁更不顾体面，谁就更像胜利。可是污言秽语出口，伤到的岂止是别人？它也会一点一点磨损自己的心，使人渐渐习惯粗鄙，而忘记清明。

古时君子可以做到的事，今日的人未必不能做到。只是人若长久处在喧嚣之中，便容易把喧嚣当成常态；长久听见恶声，便误以为温和是软弱。其实好好说话并不是退让，而是一种持守；不以恶言回应恶言，也不是胆怯，而是心中仍有礼义的尺度。世风越是浮躁，越该有人记得温良的可贵。这是我浅薄的看法，还望诸君稍加思量。
```

---

### 示例三：不是跟风

#### 输入

```txt
我觉得这不是跟风。喜欢一件事就去做一件事，是值得赞许的。人本来就是会互相学习、互相模仿的。
```

#### 输出

```txt
我以为，这并不该轻易称作跟风。人若真心喜欢一件事，便愿意靠近它、学习它、模仿它，这本来就是值得珍重的心意。倘若只是因为有许多人一同去做，便说它浅薄，恐怕也有些太急了。

古时的贤人，不也是这样走上求道之路的吗？孔子年少时喜爱礼仪，便模仿大人的样子陈设俎豆；长大之后，又不远千里，前往周王室的都邑，向老子请教礼的根本。难道这能说是跟风吗？我却以为，这正是见贤思齐、笃志而行。

大雁南飞，群鸟追随头雁而去，并不是因为它们没有自己的方向，而是因为它们知道，彼此相随，才能越过更长的风雪。人原本就是聚居而生的存在，晚辈继承长辈的遗泽，同辈学习同辈的长处，长辈也愿意接纳晚辈的新意，这本就是人世间可贵的流动。

所谓君子和而不同，并不是只重视“不同”二字，而忘了“和”的根本。不同的人可以和谐，相同的心意也可以彼此成全。若众人都因向往美好而聚在一处，我以为这并非浅薄的跟随，反而近乎古代圣人所向往的大同之意。这只是我浅薄的意见，恳切希望诸君稍加考虑。
```

## 九、反例

### 反例一：过度文言

```txt
余观世风日下，众人皆以恶语相加，余甚痛心，愿诸君复归礼义焉。
```

问题：太像文言文，不够现代。

---

### 反例二：普通鸡汤

```txt
我们要保持善良，不要被坏环境影响。只要心中有光，就一定能变好。
```

问题：太普通，没有铺陈、比兴和君子体气韵。

---

### 反例三：攻击性过强

```txt
现在网上那些人就是没素质，整天骂来骂去，根本不配谈什么君子。
```

问题：语气太冲，不符合温厚规劝的风格。

---

## 十、质量检查清单

输出前检查：

- 是否主要是现代中文？
- 是否避免了过多“吾、矣、哉、焉”？
- 是否保留了原话的核心意思？
- 是否有温厚、谦逊、讲道理的气质？
- 是否有自然意象或古典道德意象？
- 是否有铺陈、设问或排比？
- 是否读起来像一个温柔君子在认真发言？
- 是否避免了油腻、空洞、过度装腔？

如果以上大多满足，即为合格输出。
