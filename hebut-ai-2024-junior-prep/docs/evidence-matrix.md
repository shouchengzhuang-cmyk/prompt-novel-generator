# 历届作业证据矩阵

置信度含义：

- **确认**：2024 级官方培养方案直接列出；
- **高**：存在明确标注河北工业大学、课程名称和实验内容的历届公开材料；
- **中**：存在河工大相近课程/其他专业材料，或只找到部分题型；
- **低**：仅按常规课程结构预制，尚未找到本校历届题目。

| 课程 | 已发现的历史任务 | 置信度 | 本库动作 |
|---|---|---|---|
| 数据挖掘 | 数据预处理；三维数据立方体/OLAP；Apriori 频繁项集 | 高 | 三项均提供标准库实现、样例数据和测试 |
| 计算机视觉 | 实验 1：BDD100K/KITTI 车道线检测、参数对比、视频拓展；实验 2：CIFAR-10 传统特征分类与 CNN 对比 | 高（上一届公开仓库） | 提供可替换数据路径的 OpenCV/CIFAR 骨架 |
| 深度学习 | 实验 1：PyTorch 自动求导、梯度截断等基础；实验 2：回归、二分类、多分类、K 折等 MLP 任务 | 高（上一届公开仓库） | 提供两份独立脚本，避免复制历史输出 |
| 机器学习系统与平台实践 | MNIST 手写数字识别；MLP/CNN/RNN；训练可视化；后端推理；前端画板 | 高（上一届公开仓库） | 提供完整但重新设计的全栈骨架 |
| 机器学习与模式识别 | 找到河工大其他专业《模式识别》六次实验，但不是人工智能专业同课 | 中低 | 只提供通用分类基线，不宣称原题 |
| 计算智能 | 尚未锁定人工智能专业原题 | 低 | 预制 GA 与 PSO，等正式要求适配 |
| 数值分析与数值优化 | 尚未锁定原题 | 低 | 预制二分法、牛顿法、梯度下降和误差记录 |
| 自然语言处理 | 尚未锁定本课程原题 | 低 | 预制 TF-IDF 风格词袋 + 朴素贝叶斯文本分类 |
| 软件设计与编程实践 | 题目通常可能按届次变化 | 低 | 只给工程结构、测试、日志与验收清单 |

## 不能据此推出的事情

- 2024 级一定沿用上一届题目；
- 任课教师、数据集、指定框架和报告模板不变；
- 公开仓库中的学生实现就是标准答案；
- “高置信度”可以替代正式作业通知。

本库宁愿把不确定性写在脸上，也不搞“老师还没开口，AI 已经替老师出完题”这种赛博算命。
